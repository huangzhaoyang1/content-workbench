# 方案一：Tesseract OCR（推荐，稳定兼容）
# Tesseract 本体是独立的 C++ 程序，跟 Python 版本无关，Python 侧只装一个很轻的封装。
# ⚠️ 必须先装 Tesseract 本体，pip 装 pytesseract 是不够的：
#   Windows 安装包 → https://github.com/UB-Mannheim/tesseract/wiki
#   安装时务必在「Additional language data」里勾选 Chinese (Simplified) 中文语言包，
#   默认装到 C:\Program Files\Tesseract-OCR\，不会自动加进 PATH，
#   所以在「配置 → 高级」里填 tesseract.exe 完整路径，点「检测」确认可用。
# 模型（traineddata）随安装包一起装好，识别全程离线、无需联网。
